## Status

[![Phare badge](https://img.shields.io/endpoint?url=https%3A%2F%2Fstatus.monoclenetwork.org%2Fshield-badges%2Favailability.json&style=for-the-badge)](https://status.monoclenetwork.org)

The [Monocle Network Service Status](https://status.monoclenetwork.org) uses [Phare](https://phare.io) for uptime monitoring, incident reporting and service status.

## Features

- Unlimited projects, team members, integrations, alerts.
- 100,000 monitoring events
- Incident summaries
- Public status page

## Service Status Page

The Monocle Network Service Status is accessed from the domain https://status.monoclenetwork.org
